Assignment One

Consider that the Assignment Journal is 30% of each assignment grade. Now consider how much work you put into the submitted programs, worth 70% of each assignment grade. Your Assignment Journal should be several pages long, and it should cover the time period you spent on each assignment.

Trying to throw together a couple of paragraphs a few minutes (or hours) before submitting the assignment will not suffice. The marker can tell the difference between an honest effort and commentary and a hastily thrown-together document.

As part of this course, you are strongly encouraged to create your own Assignment Journal on your computer using a word processor (MS Word is a common choice). In that Journal, you will write down, on an ongoing basis, the activities you are undertaking for this course. This will help you embrace the material more quickly than if you were not keeping track of your thoughts and reflections throughout the course.

You will be graded on the information you take from your Assignment Journal and transfer to your assignments. One of the requirements for each assignment is documentation of your progress through the assignment, the difficulties you encountered, and how you overcame them.

You can create a single Journal for the whole course or create a new Journal for each assignment. The Assignment Journal entries for a given assignment should cover all the programs you write for that assignment.

This Assignment Journal should list the sources you used for your programs, including anything you found on the Internet. It should include all design decisions and assumptions you made in creating your programs. It should list anything you did in order to make your programs compile and run, no matter where the ideas came from. Finally, the Assignment Journal should contain your reflections on each assignment as a whole—what you thought of it, how you found the programming process, and what aspects of the course Learning Outcomes you believe were fulfilled by the assignment. Learning Outcomes can be found in the Course Orientation and in the course syllabus.

All assignment submissions must include all of the following deliverables:

C++ source code for a complete, working program that fulfills the requirements of the following five (5) problems; additional files as described in the requirements for each problem; full documentation and a test plan for your primary C++ source code file as described in the Assignment Requirements; and reflections on the assignment (Assignment Journal) as described in the Assignment Requirements.
